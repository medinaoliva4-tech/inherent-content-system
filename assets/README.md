# Assets

Inputs livianos del cliente que deban vivir en el repo. No es la biblioteca de media.

## Inventario

Mantener `ASSET_INDEX.md` actualizado cuando el volumen lo justifique. El índice ayuda a Claude a seleccionar material sin depender solo de nombres de archivo.

## Estructura

- `brand/` — logos, packaging, menús y archivos oficiales livianos cuando sea necesario versionarlos.
- `video/` — documentación o punteros de video, no biblioteca permanente.
- `audio/` — documentación o punteros de audio, no biblioteca permanente.

## Regla

Las imagenes y videos reales viven en Jockey. `assets/` no debe duplicar originals, references, generated ni final assets.
