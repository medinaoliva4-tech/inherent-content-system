# Integrations

Las integraciones son brazos de ejecución. No contienen estrategia ni verdad de marca.

## Principales

- `figma/` — Figwright como ruta primaria de diseño local hacia Figma Desktop.
- `higgsfield/` — generación visual con original + referencia + review gate.
- `apify/` — scraping/research de señales para hipótesis de contenido.
- `metadata2go/` — limpieza de metadata del archivo final publicable.

## Regla

Leer `OPERATIONS.md` para setup end-to-end y `CONNECTIONS.md` para el estado real. Un README no equivale a una integración conectada.
