# Brand Context

Este folder contiene la verdad específica de la marca activa. Cambia para cada cliente; la metodología de `context/` no cambia.

## Regla importante

Los README son guías de carga. Los archivos de perfil son plantillas hasta que se completen con hechos reales.

Un repo no se considera completo si estos archivos siguen con campos críticos `POR DEFINIR` para la producción solicitada.

## Archivos base por área

- `brand/BRAND_PROFILE.md`
- `icp/ICP_PROFILE.md`
- `offer/OFFER_CATALOG.md`
- `content/CONTENT_SYSTEM.md`
- `design/BRAND_WORLD_ADAPTATION.md`
- `design/DESIGN_SYSTEM.md`
- `design/PHOTOGRAPHY_SYSTEM.md`
- `calendar/CALENDAR_STATUS.md`
- `analytics/PERFORMANCE_BASELINE.md`
- `community/COMMUNITY_PROFILE.md`
- `founder/FOUNDER_PROFILE.md`
- `competitors/COMPETITOR_MAP.md`
- `research/RESEARCH_LOG.md`

## Uso

1. cargar evidencia real;
2. completar las plantillas pertinentes;
3. mantener `CONFIRMADO`, `HIPÓTESIS` y `POR DEFINIR` cuando ayude a distinguir certeza;
4. pasar `PROJECT_READINESS.md` antes de marcar el repo como listo.
