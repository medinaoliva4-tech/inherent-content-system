# Design — contexto específico de la marca

Aquí vive el sistema visual APROBADO para el cliente activo.

Este README es scaffolding; no contiene hechos del cliente.

## Archivos obligatorios para producción de diseño

- `BRAND_WORLD_ADAPTATION.md` — qué se tomó, adaptó, rechazó o dejó pendiente del brand world maestro.
- `DESIGN_SYSTEM.md` — reglas visuales finales aprobadas y fuente Figma.
- `PHOTOGRAPHY_SYSTEM.md` — dirección fotográfica recurrente cuando aplique.

## También puede contener
- paleta y códigos de color;
- tipografías aprobadas y licencias/uso;
- reglas de logo;
- composición/grid;
- fotografía y dirección de arte;
- iconografía/ilustración;
- motion;
- componentes Figma;
- do/don't;
- ejemplos aprobados.

Binarios de imagen/video deben vivir en Jockey. El repo guarda reglas, IDs, links y decisiones.

## Autoridad

Cuando exista conflicto entre `brand_world_reference/` y una decisión documentada aquí, manda este folder.

## Figwright

Antes de diseñar, Claude Code debe leer este folder y ejecutar `skills/design-with-figwright/SKILL.md`.

La existencia de estos archivos no significa que estén completos: `PROJECT_READINESS.md` debe validar que sus campos críticos ya no estén `POR DEFINIR` para la tarea de producción.
