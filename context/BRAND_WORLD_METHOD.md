# BRAND_WORLD_METHOD.md — Adaptar un mundo visual central sin copiarlo

## Propósito

Definir cómo convertir un brand guideline / brand world de inspiración central en un sistema propio para cada cliente.

Este archivo es metodología reusable. No contiene decisiones de ningún cliente.

## Distinción clave

```text
brand_world_reference/
= punto de partida creativo

brand_context/design/
= decisiones finales del cliente
```

El brand world maestro puede ser muy cercano al gusto del director creativo. Aun así, no debe asumirse que logos, fuentes, paletas o recursos pasan automáticamente a la marca nueva.

## Paso 1 — Descomponer el brand world

Analizar por separado:
- lógica de logo / símbolo / wordmark;
- tipografía;
- color;
- grid y layouts;
- jerarquía;
- fotografía;
- dirección de arte;
- texturas;
- iconografía;
- ilustración;
- motion;
- packaging / aplicaciones;
- tono sensorial general.

No describir solo “me gusta / no me gusta”. Extraer principios transferibles.

## Paso 2 — Clasificar cada componente

Usar una de estas decisiones:

### KEEP
Puede conservarse prácticamente tal cual porque Dirección Creativa lo aprueba y no compromete diferenciación, viabilidad o propiedad de terceros.

### ADAPT
Conservar el principio, pero rediseñar para el cliente.

### INSPIRE
Solo debe influir en sensación o dirección. No trasladar elementos concretos.

### REJECT
No usar en la marca activa.

### TBD
Aún no hay decisión.

## Paso 3 — Adaptar logos con especial cuidado

Para logos/referencias identitarias:
- extraer nivel de simplicidad;
- proporción;
- relación símbolo-wordmark;
- geometría;
- modularidad;
- ritmo;
- sensación de masa/espacio;
- lógica del sistema.

No copiar nombre, símbolo, monograma, geometría distintiva ni composición identificable de una marca existente.

El resultado debe sentirse dentro del mundo deseado y, al mismo tiempo, ser una identidad propia del cliente.

## Paso 4 — Tipografía

Si una fuente gusta especialmente:
1. comprobar si Dirección Creativa quiere conservarla;
2. verificar si su uso es viable para el proyecto;
3. si no se conserva, describir sus atributos (contraste, serif/sans, ancho, ritmo, altura x, sensación editorial, etc.);
4. buscar/adaptar una solución con el mismo papel estratégico, no necesariamente la misma fuente.

## Paso 5 — Registrar la decisión

Toda decisión final debe documentarse en:

`brand_context/design/BRAND_WORLD_ADAPTATION.md`

No modificar el brand world maestro para fingir que siempre fue la identidad del cliente. Mantener trazabilidad entre inspiración y adaptación.

## Paso 6 — Promover a Design System

Solo lo aprobado pasa a:
- `brand_context/design/DESIGN_SYSTEM.md`;
- `brand_context/design/PHOTOGRAPHY_SYSTEM.md` cuando aplique;
- assets oficiales de la marca.

## Principio final

**Inspiración central ≠ identidad final.**

El sistema debe permitir reutilizar una dirección creativa fuerte entre múltiples clientes sin convertirlos en copias entre sí.
