# media/

Este folder reemplaza el uso de `assets/originals/`, `assets/references/` y `outputs/images/` como bibliotecas fisicas.

Aqui solo viven punteros, IDs, indices, reglas y metadata. Las imagenes y videos viven en Jockey.

Archivos:
- `JOCKEY_LIBRARY.md` — link/Store ID y regla principal.
- `MEDIA_INDEX.md` — inventario logico por asset need.
- `COLLECTIONS.md` — estructura esperada en Jockey.
