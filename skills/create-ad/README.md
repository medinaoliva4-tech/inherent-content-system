# /create-ad

Skill operativa del sistema Inherente.

## Reglas base
- Respetar `CLAUDE.md` y la metodología de `context/`.
- Leer el contexto específico disponible en `brand_context/`.
- No escribir datos particulares de un cliente dentro de `context/`.
- Si la salida requiere diseño en Figma, pasar primero el Design Context Gate y después usar `skills/design-with-figwright/SKILL.md`.
- Si requiere fotografía nueva, preparar el brief y usar la skill de Higgsfield correspondiente.
- Guardar entregables en el subfolder correcto de `outputs/`.
