# Skills

Las skills son procedimientos repetibles. No contienen la verdad de la marca ni reemplazan la metodología.

Antes de ejecutar una skill:
1. leer `CLAUDE.md`;
2. verificar `STATUS.md` cuando la tarea sea de producción;
3. leer el contexto específico necesario en `brand_context/`;
4. usar `brand_world_reference/` solo bajo las decisiones de adaptación aprobadas.

Skills clave de producción:
- `design-with-figwright/` — ejecución de diseño local en Figma.
- `higgsfield-generate-image/` — generación de fotografía nueva con original + referencia + observación humana.
- `generate-images/` — preparación metodológica de imágenes y brief.

Los demás folders representan operaciones de contenido/campaña y pueden seguir ampliándose sin mover datos de cliente a `context/`.
