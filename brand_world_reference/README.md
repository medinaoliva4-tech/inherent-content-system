# Brand World Reference

Este folder contiene el brand guideline / brand world maestro que Dirección Creativa entrega como punto de partida visual.

No es la identidad final del cliente y no se aplica automáticamente.

## Primero

Completar `INVENTORY.md` para registrar qué material está realmente cargado.

## Subfolders

- `guideline/` — documento(s) fuente.
- `logos/` — referencias de construcción de logo/wordmark.
- `typography/` — fuentes, muestras o sistemas tipográficos de inspiración.
- `color/` — paletas y relaciones cromáticas.
- `layouts/` — composición, grids y jerarquías.
- `photography/` — dirección fotográfica macro.
- `graphic_elements/` — recursos, iconografía, texturas, patrones.
- `references/` — otras referencias del universo.

## Adaptación

Cada componente debe terminar clasificado para el cliente como `KEEP`, `ADAPT`, `INSPIRE`, `REJECT` o `TBD` en:

`brand_context/design/BRAND_WORLD_ADAPTATION.md`
