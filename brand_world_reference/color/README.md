# Color

Este folder pertenece al brand world maestro y sirve como inspiración reusable. No representa automáticamente una decisión aprobada para el cliente.

## Puede contener
- paletas de inspiración;
- relaciones de contraste;
- usos de fondos/accentos;
- muestras de grading si funcionan como sistema;

## Al usarlo
Clasificar lo relevante como `KEEP`, `ADAPT`, `INSPIRE`, `REJECT` o `TBD` y registrar la decisión en `brand_context/design/BRAND_WORLD_ADAPTATION.md`.
